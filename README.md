## 📋 재현·통과 확인 4가지 (T04-C27 필수 규격)

1. **어디로 가나요**: 
   공개 결과물 URL ([https://wkdtlgns99-cell.github.io/aleph-t04/](https://wkdtlgns99-cell.github.io/aleph-t04/))에 새 시크릿 창으로 접속합니다.
2. **무엇을 하나요 (3단계 이내)**: 
   - **1단계**: 메인 화면에서 대전광역시 실시간 기온(°C), 단위, 출처, 원천 관측시각, 조회시각, 기준시간대(Asia/Seoul)를 확인합니다.
   - **2단계**: 헤더 우측의 `[🧪 채점관 합성 검사기]` 버튼을 클릭하여 테스트 모달을 엽니다.
   - **3단계**: `▶️ 정상 시퀀스 실행`, `타임아웃(5대 장애 중 1택)`, `▶️ 장애 후 회복 실행`을 차례로 클릭하여 상태 전이와 마지막 정상값(105pt) 보존을 확인합니다.
3. **무엇이 보이면 통과인가요**: 
   실시간 대전 기온과 메타데이터 6대 요소가 완벽하게 표시되고, 합성 검사기에서 장애 시뮬레이션 시 마지막 정상값(105pt)이 사라지지 않고 `stale` 뱃지와 함께 보존되며, 회복(RECOVER-D2) 시 `fresh / none` 및 익일 신규 행(+15pt 변화)으로 깨끗하게 복구되면 통과입니다.
4. **안 될 때 무엇이 보이나요**: 
   네트워크가 끊기거나 외부 API 지연이 발생하면 기존 정상 관측값이 그대로 유지된 채 상단에 주황색 `오래된 값 (STALE: TIMEOUT / OFFLINE)` 경고 알림 박스와 함께 명확한 실패 사유 및 `[🔄 다시 시도]` 버튼이 노출됩니다.
